# F00 — карточка проверки на телефоне

Сборка: APK из GitHub Actions, прогон **41891754748** (ветка `android`, коммит `935ca64`):
<https://github.com/Greg0rd/horizon-android/actions/runs/41891754748>. Артефакт
`horizon-dev-9-arm64-v8a` → внутри `Horizon-Android-dev.9.935ca64a1cdc-arm64-v8a.apk`.

**Уже проверено 2026-11-04 через adb на вашем телефоне** (OnePlus 10 Pro): установка,
подпись **HZD**, лог `HZD layer active (hzd-survival 0.1.0)`, `HZD 0.1.0` в F3, ввод
команды с экранной клавиатуры, `[file/hzd]` в `/datapack list` и ответ `HZD data pack
active` на `/function hzd:ping` — в новом мире и после обновления приложения. Осталось
только **пункт 6: замеры «до»** (и, если захотите, беглый взгляд на пункты 1–5).
Тестовый мир «Новый мир» с включёнными командами можно удалить.

## 1. Приложение ставится и называется «HZD»

Скачайте артефакт (Actions → прогон → Artifacts), распакуйте zip, поставьте APK:

```bash
adb install -r Horizon-Android-dev.9.935ca64a1cdc-arm64-v8a.apk
```

- [x] В лаунчере значок подписан **HZD** (не «Horizon Android»).
- [x] Миры и настройки от прошлой установки на месте (пакет тот же, `-r` поверх).
- [x] Игра запускается, мир открывается как обычно.

## 2. Лог говорит, что слой HZD включён

```bash
adb logcat -d | Select-String "HZD layer active"
```

- [x] Есть строка `HZD layer active (hzd-survival 0.1.0)` (проверено).

## 3. F3 показывает версию слоя

Три пальца по экрану (или клавиша F3 при подключённой клавиатуре), смотрите блок `system`.

- [x] В блоке `system` есть строка `HZD 0.1.0` (проверено).
- [ ] Скриншот этого блока — в ответ.

## 4. Консоль работает с экранной клавиатурой

Откройте чат, введите команду, отправьте.

- [x] Клавиатура открывается сама, команда набирается и отправляется (проверено).
- [ ] `/time set night` — наступает ночь.
- [ ] `/tp 0 100 0` — телепорт срабатывает (если разрешены читы в мире).
- [ ] Enter на клавиатуре отправляет команду (а не только кнопка «Отправить»).
- [ ] Скриншот открытой клавиатуры с командой — в ответ.

## 5. Датапак HZD сам появился в новом и в старом мире

Новый мир: «Создать новый мир» → играть.

```
/datapack list
/function hzd:ping
```

- [x] `/datapack list` показывает `[file/hzd (мировой)]` (проверено).
- [x] `/function hzd:ping` отвечает в чате `HZD data pack active` (проверено).
- [x] То же самое после обновления приложения на новый APK: пак и его функция работают (проверено).
- [ ] Экран «Датапаки» (Esc → Датапаки / кнопка мира) показывает пак `hzd` включённым.
- [ ] Скриншот `/datapack list` — в ответ.

Если пак не появился, посмотрите лог:

```bash
adb logcat -d | Select-String "HZD: built-in data pack"
```

## 6. Замеры «до» (это главное для следующих модулей)

В том же новом мире, с настройками по умолчанию, F3 открыт. Для каждой сцены
скопируйте цифры и экспортируйте запись производительности (пауза → экспорт записи;
файл `.jsonl`).

| Сцена | Что делать | Что записать |
|---|---|---|
| (a) | 2 минуты идти по лесу | FPS (средний и 1 % low), tick ms (средний и максимум), render distance, LOD distance |
| (b) | пройти через деревню | то же |
| (c) | 1 минуту быстро летать | то же |
| (d) | 20 минут смешанной игры | то же + заряд батареи до/после, «телефон греется?» |

- [ ] Скриншоты F3 каждой сцены.
- [ ] Экспортированные `.jsonl` (или их папка).
- [ ] Заряд батареи до/после сцены (d) и субъективно: греется или нет.

## 7. Что прислать назад

1. Скриншоты: значок HZD, F3-блок `system`, `/datapack list`, открытая клавиатура.
2. Лог `adb logcat -d > log.txt` (целиком, не обрезанный).
3. Экспорт производительности для всех четырёх сцен.
4. Ответы по пунктам 1–6 (галочки + пара слов там, где что-то пошло не так).
5. Если что-то не так — время и описание, что именно делали.

После этого цифры попадут в `hzd/docs/BASELINE.md`, и F01 можно начинать.
