## 1. What was built

F00 put HZD's own layer into the fork without touching vanilla behaviour: a `hzd/` tree with
the running documents (`PROGRESS`, `DECISIONS`, `HZD_DIVERGED`, `CONSOLE`, `BASELINE`) and the
owner's test card, a root `HZD.md`, a pointer in `AGENTS.md`, and a new
`crates/hzd-survival` in the workspace. The crate embeds `hzd/datapack` at build time
(`build.rs`, one `include_bytes!` per file) and writes it into `<world>/datapacks/hzd` every
time a local world opens, so a new world, a re-created world and a world made before this
build all get the pack; the game's own pack-list rules enable a `file/` pack a world's
`datapacks.json` does not mention, and a world that disabled `file/hzd` is left alone. The
layer's version shows up twice (log banner `HZD layer active (hzd-survival 0.1.0)` and the F3
`system` group), and `hzd_survival::perf::lines()` is wired into the same overlay for later
counters. `.github/workflows/hzd-check.yml` adds the minutes-long check (fmt, clippy
`-D warnings`, tests, the public-tree check, and `cargo check -p horizon-client`). The app's
launcher label is now `HZD`, with the fork's package id unchanged so an update installs in
place over the owner's current build.

## 5. Decisions, hooks, limitations

Decisions (details in `hzd/docs/DECISIONS.md`): upstream frozen at `6eca278f`; one branch per
module merged into `android` when green; the data pack ships embedded in `hzd-survival` and is
installed on world open rather than at create time (the only way existing worlds get it
without a create-screen change); the app keeps the fork's package id; no resource-pack
auto-enable until F04 has art to show; version in the log and F3.

`// HZD:` hooks added (all listed in `HZD_DIVERGED.md`):

- `Cargo.toml` — workspace member `crates/hzd-survival` (comment, not a code hook).
- `crates/horizon-client/Cargo.toml` — dependency on `hzd-survival`.
- `crates/horizon-client/src/main.rs` — one log line after the build banner.
- `crates/horizon-client/src/game.rs` (`Game::open_world`) — 10 lines writing the pack into the
  world before it opens.
- `crates/horizon-client/src/game/debug_keys.rs` (`debug_system_lines`) — the F3 line and the
  counters loop.
- `packaging/android/AndroidManifest.xml` — `android:label="HZD"`.
- `AGENTS.md` — a pointer section to `HZD.md`.

Limitations:

- The pack is installed when a **local** world opens. A world opened straight from a server
  (a dedicated server or a LAN host's own `--world`) never runs `Game::open_world`; the
  dedicated server would need its own call when we host HZD worlds there (F13).
- The pack has one function (`hzd:ping`). It is the F00 proof, not content.
- **Dot files are skipped** by `build.rs`, and everything under `hzd/datapack` is embedded:
  a pack file larger than a few MB would grow the binary (fine at 16×16 and JSON data).
- The `/hzd` command tree does not exist yet; F00's test hook is the pack's function.
